
# 🎯 Mapeia Lead

**Sistema de Prospecção Inteligente por CNAE e Região**

Desenvolvido por: **Glailton Nascimento**

---

## 📋 Sobre o Projeto

O Mapeia Lead é uma ferramenta para profissionais de prospecção comercial que precisam encontrar **todas as empresas ativas** de um determinado segmento (CNAE) em uma região específica.

---

## 🎯 Para que serve

- Buscar empresas por segmento para oferecer franquias
- Encontrar potenciais clientes B2B por região
- Prospectar por CNAE (qualquer setor)
- Análise de mercado por localização

---

---

## 🖥️ Como usar

### Passo 1: Digite o CNAE
Exemplo: `56120` (sorveterias) ou `47211` (mercados)

### Passo 2: Escolha o estado
Selecione SP, RJ, MG ou outro

### Passo 3: Clique em Buscar
O sistema retorna todas as empresas ativas

### Passo 4: Exporte os resultados
Baixe um arquivo CSV para sua planilha
